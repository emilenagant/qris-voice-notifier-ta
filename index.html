QRIS Voice Notifier IoT

Proyek embedded system berbasis ESP32 untuk memberikan notifikasi suara realtime saat transaksi QRIS berhasil diterima.

Tentang Pengembang

Saya Teuku M. Aqbil, mahasiswa Politeknik Negeri Medan. Website ini dibuat sebagai bagian dari pengembangan proyek tugas akhir pada program studi Teknik Komputer.

Saat ini saya sedang mengembangkan sebuah perangkat IoT berbasis ESP32 yang berfungsi sebagai notifikasi pembayaran QRIS berbasis suara untuk merchant, UMKM, warung, kios, dan penggunaan kasir sederhana.

Project ini digunakan untuk keperluan pengembangan, pengujian API, integrasi sistem, serta kebutuhan akademik tugas akhir.

Fitur

  • Monitoring transaksi QRIS realtime
  • ESP32 embedded platform
  • Speaker audio notification
  • REST API integration
  • Designed for UMKM & merchant kecil

Deskripsi Produk

Perangkat ini digunakan oleh merchant, warung, kios, booth makanan, dan UMKM agar pembayaran QRIS dapat diketahui tanpa harus terus melihat aplikasi pembayaran.

Ketika transaksi diterima, speaker akan mengumumkan nominal pembayaran secara otomatis melalui speaker internal.

Tujuan Sistem

Tujuan dari sistem ini adalah memberikan solusi notifikasi pembayaran QRIS yang praktis, murah, dan mudah digunakan tanpa memerlukan monitor tambahan atau pengecekan aplikasi secara terus-menerus.
