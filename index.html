QRIS Voice Notifier IoT

Proyek embedded system berbasis ESP32 untuk memberikan notifikasi suara realtime saat transaksi QRIS berhasil diterima.

Fitur

  • Monitoring transaksi QRIS realtime
  • ESP32 embedded platform
  • Speaker audio notification
  • REST API integration
  • Designed for UMKM & merchant kecil

Deskripsi Produk

Perangkat ini digunakan oleh merchant, warung, kios, booth makanan, dan UMKM agar pembayaran QRIS dapat diketahui tanpa harus terus melihat aplikasi pembayaran.

Ketika transaksi diterima, speaker akan mengumumkan nominal pembayaran.
